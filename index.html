Guide d'installation Android

Comment installer mes applications Android ?

Les applications sont hébergées sous forme de fichiers d’installation APK officiels sur Google Drive.

01

Accéder au Google Drive

Cliquez sur le bouton de téléchargement pour ouvrir le répertoire officiel où sont stockés tous les fichiers APK.

Étape vérifiée
02

Télécharger le fichier APK

Choisissez l’application de votre choix et téléchargez le fichier .apk directement sur votre appareil Android.

Étape vérifiée
03

Autoriser les sources externes

Si demandé par Android, autorisez l’installation depuis votre navigateur ou gestionnaire de fichiers dans Paramètres.

Étape vérifiée
04

Lancer l’installation

Appuyez sur le fichier téléchargé dans vos notifications pour finaliser l’installation en quelques secondes.

Étape vérifiée

Prêt à installer les applications ?

Retrouvez la dernière version des APK directement sur le Drive officiel.
